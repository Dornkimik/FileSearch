# File Search

> [!WARNING]
> ## ⚠️ This application was made entirely with AI
>
> **Every line of code, the design and this README were generated by an AI model (Claude, by Anthropic).**
> No part of it was written by hand. It has only been tested briefly on a single Windows 11 machine.
> It may contain bugs, inefficiencies or security issues. Review the code before relying on it, and use it at your own risk.

A fast, minimal file-name search app for Windows, written in Rust with [egui](https://github.com/emilk/egui).
It searches **names and paths only**. It never reads file contents.

## Features

- **Instant results.** All fixed drives are indexed into a compact in-memory index, so each keystroke searches millions of entries in milliseconds.
- **Fast indexing.** Folders are scanned in parallel without following junctions. The index is cached at `%LOCALAPPDATA%\FileSearch\index.bin`, so later launches show results right away while a fresh scan runs in the background.
- **Search modes**
  - *Contains*: space-separated words must all appear (`report 2024`). Use `-word` to exclude a word.
  - *Wildcard*: `*.pdf`, `IMG_????.jpg`.
  - *Regex*: full regular expressions.
  - **Aa** turns on case-sensitive matching. **Path** matches against the full path instead of only the name (`projects\notes .md`).
- **Filters**: files or folders, categories (Documents, Images, Audio, Video, Archives, Code, Programs), custom extensions, size range, modified date and location (folder).
- **Less clutter.** System files are hidden by default: anything in Windows, Program Files, ProgramData or AppData, plus items Windows marks as system files. Hidden items are also off by default. Each has its own checkbox in the sidebar.
- **Exclude folders**: right-click any result and use **Exclude folder ▸** to pick that folder or any folder above it. Excluded folders are listed in the sidebar, where ✕ removes one, and they are remembered between launches.
- **Results**: sortable columns (Name, Folder, Size, Modified), a right-click menu (Open, Show in Explorer, Copy path, Copy name), and light and dark themes.

## Keyboard

| Key | Action |
| --- | --- |
| `Ctrl+F` | Focus the search box |
| `↑` / `↓`, `PgUp` / `PgDn` | Move the selection |
| `Enter` | Open the selected item |
| `Shift+Enter` | Show the selected item in Explorer |
| `Esc` | Clear the search |

## Build

```bash
cargo build --release
```

The executable is written to `target\release\file_search.exe`.

## Layout

- `src/index.rs`: the compact index, the parallel scanner and the on-disk cache
- `src/search.rs`: filters, query compilation, the parallel matcher and the search worker thread
- `src/app.rs`: the UI
- `src/theme.rs`, `src/icons.rs`: styling and vector icons
- `src/util.rs`: drive detection, opening files, formatting
